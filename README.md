# Apex Market Pulse

A single-page market dashboard built by Vadym Rogynskyi with Claude.

**Live site:** https://vadym-rogynskyi.github.io/apex-market-pulse/

The whole site is one file, `index.html`. Open it in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

For learning and demonstration only. Not investment advice.
